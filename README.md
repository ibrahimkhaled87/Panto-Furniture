Full Stack MERN E-commerce Web Application

Technilogies Used:
- Frontend: React.js, SCSS
- Backend: Node, Express.js
- Database: PostgreSQL

Features Implemented:
- Landing Page
- Shop page: debounced search + pagination
- Dynamic product pages from path params
- Persistent cart for guests using localStorage and React Context
- Checkout with paymob payment integration.
- Signup/Login authentication with jwt and password hashing (bcrypt) + protected routes
- Admin Side with analytics dashboard, products CRUD, orders and users management.
- User Side with order-tracking and account settings
